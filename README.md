# TP2 - Paradigmas de Programación

En este trabajo práctico se continúa el desarrollo del TP1 incorporando nuevos conceptos de Java.

## Ejercicio 1
- Manejo de excepciones mediante `CupoExcedidoException`.
- Control de cupos en las inscripciones.
- Persistencia mediante serialización y deserialización.
- Uso de `try-catch-finally`.

## Ejercicio 2
- Creación de la interfaz `Certificable`.
- `Taller` y `Curso` implementan la interfaz.
- Generación de certificados para estudiantes.
- `Charla` no es certificable.

## Ejercicio 3
- Implementación de métodos genéricos para filtrar actividades por tipo.
- Uso de `List<? extends Actividad>` para calcular costos de materiales.
- Aplicación de genéricos, wildcards y polimorfismo.
